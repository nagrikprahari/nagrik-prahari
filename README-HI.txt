नागरिक प्रहरी — शुरुआती वेबसाइट फाइलें

इस ZIP में:
1. index.html — वेबसाइट की मुख्य संरचना
2. style.css — रंग, डिजाइन और मोबाइल लेआउट
3. script.js — मेन्यू और समाचार खोज/फिल्टर
4. README-HI.txt — यह निर्देश

लैपटॉप पर कैसे खोलें:
1. ZIP फाइल पर Right-click करें और Extract All चुनें।
2. निकले हुए nagrik_prahari_site फोल्डर को खोलें।
3. index.html पर डबल-क्लिक करें। वेबसाइट ब्राउज़र में खुल जाएगी।
4. कोड बदलने के लिए VS Code में File > Open Folder चुनकर यही फोल्डर खोलें।

महत्वपूर्ण:
- यह केवल शुरुआती static frontend है।
- इसमें अभी वास्तविक Admin Login, Database, User Registration या AI सुविधा नहीं है।
- पासवर्ड, API keys या secret keys HTML/JavaScript में कभी न डालें।
- समाचार प्रकाशित करने से पहले मूल स्रोत, तारीख और तथ्य जाँचें।
- यह निजी स्वतंत्र मंच है, सरकारी/पुलिस/न्यायालय की आधिकारिक वेबसाइट नहीं।
